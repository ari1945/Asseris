## 2. Cara bekerja (ringkas; rinciannya di `AGENTS.md` §2)

```bash
npm run verify            # dari root — cermin persis CI; WAJIB hijau sebelum push
```

- `master` **selalu hijau** (BUILD.md §R-7). Cacat yang direpro tapi belum ditutup dikirim
  sebagai `it.fails()` / `it.skip()` + `// KARANTINA s/d <tanggal>`.
- Alur PR: buat cabang → `npm run verify` → push → PR → bila master bergerak `gh pr
  update-branch` dan tunggu CI ULANG → `gh pr merge --squash` → hapus cabang remote manual
  → tunggu 4 workflow master. CI bisa **tidak pernah start** walau PR `CLEAN` (GitHub
  menjatuhkan dispatch); obatnya `gh pr close` + `gh pr reopen`.
- Sebelum menyentuh cabang/berkas apa pun: `git status --short` dan sensus **blob**
  (`AGENTS.md` §8, butir squash). `git cherry`/"N ahead" menyesatkan di repo ini.
- Ratchet `:any` memerah **dua arah** (menambah → `check-any-ratchet`; menghapus →
  suppression basi, `eslint` exit 2). Penulis tunggal: `npm run lint:any-baseline`.
- Uji `.ts` wajib bebas `any` (`typecheck:test` adalah gerbang).
- UI Bahasa Indonesia; skala tipografi 8 ukuran, lantai 11px (`AGENTS.md` §5); token
  warna, bukan hex; kontrol form native.
